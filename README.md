# 🎣 Phishing Demo · 钓鱼网站安全教育演示

> **仅用于安全教育。** 这是一个仿 QQ 登录页的教学演示：当演示对象输入账号密码并点击"登录"后，页面会**立即自我揭示**这是钓鱼网站——并且在**整个过程中不记录、不存储、不发送任何输入内容**。

**在线演示**：<https://principia-rain.github.io/phishing-demo/>
**源码**：整个网站只有一个 [`index.html`](index.html)，无构建、无后端、无任何依赖。

## 流程

1. 打开页面 → 一个高仿 QQ 邮箱登录页（在此之前没有任何提示，这正是演示重点：**看起来完全正常的登录页有多容易仿造**）
2. 输入任意账号密码 → 点击"登录" → 短暂"登录中"
3. 页面立即揭示：**"你被钓鱼了"**，并展示
   - 你刚才的输入（密码默认打码，点击显示）
   - 三条"零记录"证据 + F12 自查方法
   - 真钓鱼站在同一时刻会做什么
   - 防钓鱼三招
   - 本仓库地址（供源码审计）

## 为什么可以确定"什么都没被记录"（审计指南）

欢迎审计，这也是本项目的核心价值：

- **单文件**：全部代码就是 `index.html`，逐行可读
- **零外部资源**：页面不加载任何 CDN 脚本、字体、图片、统计代码——你输入的内容在物理上**无处可发**（连"扫码登录"的二维码都是 Canvas 本地随机画的装饰图）
- **零外发代码**：在仓库里搜索 `fetch`、`XMLHttpRequest`、`sendBeacon`、`localStorage`、`document.cookie`，命中 **0** 处
- **自查 30 秒**：页面上按 `F12` → Network 面板 → 勾选 Preserve log → 重新输入并点"登录" → Network 面板**不会出现任何新请求**；Application 面板里也找不到任何 cookie / localStorage 写入

## 使用须知（重要）

- 适用场景：自我教育、课堂演示、对**知情同意**的朋友做演示（页面的设计就是"输完立刻揭示"，请勿移除揭示逻辑后使用）
- 本项目**不提供**任何真正窃取凭据的能力；未经同意获取他人账号密码属于违法行为（《刑法》第 285/286 条、《网络安全法》等）
- 请勿将本演示用于冒充真实机构骗取信息

## 部署 / 自定义

- 部署：GitHub Pages（`main` 分支根目录），push 即自动上线
- 改成其他品牌（银行/教务/网盘）：改 `index.html` 里的 logo、文案即可
- 揭示延迟：搜 `setTimeout(reveal, 1400)` 调整毫秒数
